# Muebles del campus

Vistas previas de muebles de Habbo descargadas de https://www.habboassets.com (CDN `cdn.habboassets.com/derived/furni/...`).

El tamaño de cada PNG está en `lib/campus/furni.ts` (`FURNI_SIZE`): si agregas uno, regístralo ahí.
